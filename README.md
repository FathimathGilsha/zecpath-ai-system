# Zecpath AI System

## Project Overview
This project is designed to build a modular AI recruitment platform using multiple AI services. The system analyzes resumes, screens candidates, conducts interview intelligence, performs behavior analysis, and generates candidate scores.

## Project Structure

- data/ - Stores datasets and candidate files
- parsers/ - Resume parsing modules
- ats_engine/ - ATS filtering service
- screening_ai/ - Candidate screening AI
- interview_ai/ - Interview intelligence modules
- scoring/ - Candidate scoring engine
- utils/ - Utility functions and logging
- tests/ - Test scripts
- logs/ - System log files

## Technologies Used

- Python 3.13
- Virtual Environment (venv)
- Logging Module
